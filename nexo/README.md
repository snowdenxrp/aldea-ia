# Nexo

Nexo is a local-first, persistent, modular personal AI system.

## Architecture

- **Core**: identity, state, orchestration, planning, governance.
- **Memory**: contextual, semantic, episodic and persistent memory.
- **Models**: model-agnostic routing and adapters.
- **Agents**: specialized roles coordinated by the orchestrator.
- **Tools**: explicit capabilities with permissions and auditability.
- **Runtime**: platform-specific resident integration.
- **Security**: integrity, authorization, threat detection and safe operation.
- **Recovery**: diagnosis, sandbox repair, verification and rollback.
- **Vault**: portable preservation of Nexo identity, memory and configuration.
- **Chronicle**: factual history and versioned continuity.
- **Offline**: local knowledge and resilient operation without internet.
- **Cyber**: authorized defensive security laboratory.
- **UI**: presentation layer; UI failure must not terminate Core.

## Development rule

A capability is complete only when it works, is tested, recoverable, documented and does not regress existing behavior.
