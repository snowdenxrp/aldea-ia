# NEXO CONTINUITY SYSTEM (NCS)

NCS is the official continuity entry point for the new Nexo architecture.

## Operating command
The user command **NCS** means:
1. recover NCS/STATUS;
2. read the authoritative MASTER and CORE references;
3. read BUILD for the exact construction point;
4. continue without replaying historical research;
5. consult RESEARCH/PROOF only when evidence is required.

## Separation rule
Historical V1–V20, AB104/AB105, TLC, Kafka/G0 and Lúmina research remain historical evidence. They are not dependencies of the new Nexo Core.

## Sources of truth
- MASTER: what Nexo is and must become.
- CORE: architectural contracts and invariants.
- BUILD: current implementation state.
- RESEARCH: historical investigations and extracted evidence.
- PROOF: tests, experiments and verified claims.
- DECISIONS: closed architectural decisions.
- STATUS: exact operational resume point.

No document may silently override another layer.
