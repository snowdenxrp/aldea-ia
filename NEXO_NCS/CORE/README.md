# NEXO CORE

This directory defines how the protected Nexo foundation works.

Canonical protected-transition skeleton:
PROPOSAL → CLAIM → AUTHORITY → ISOLATION → CANDIDATE → FINAL VALIDATION → CONDITIONAL COMMIT → OUTCOME → RECONCILIATION

The Core protects identity, Constitution, authority, state integrity and continuity. Higher capabilities must use these boundaries rather than bypass them.

Existing implementation evidence is consulted through adapters/contracts; legacy orchestration is not the Core.
