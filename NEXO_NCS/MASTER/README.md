# NEXO MASTER

This directory defines the product/architectural vision: what Nexo is.

The complete master vision supplied by Kevin on 2026-10-08 is the governing vision baseline for the new architecture.

Key rule:
Nexo is not a model, OS, device, UI or Lúmina. It is the persistent identity/continuity/authority system that can use those things without becoming dependent on any one of them.

Future additions are classified 🟢 RECOVERED / 🔵 EXTENSION / 🔴 CONFLICT before integration.
