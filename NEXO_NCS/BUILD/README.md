# NEXO BUILD

This directory records active construction only.

Every checkpoint must record:
- exact step;
- files changed;
- tests actually run;
- evidence;
- unverified claims;
- UNKNOWN/PENDING;
- blockers;
- next action;
- DO-NOT-REPEAT.

Construction rule:
If implementation reveals a structural problem, stop construction, correct the architecture, then resume. No compatibility patch is accepted as a substitute for a sound design.
