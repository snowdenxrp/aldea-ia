# NEXO AB104.749R — lower-level NetworkClient correlation mismatch re-audit

Date: 2026-09-28
Source baseline: Apache Kafka abf522e1ca5d7f4375baddc4da004da9fcb6e9ca

## Direct source findings

`NetworkClient.handleCompletedReceives(...)` iterates selector completed receives, obtains the source, then calls `inFlightRequests.completeNext(source)` BEFORE calling `parseResponse(receive.payload(), req.header)`.

`NetworkClient.parseResponse(...)` delegates to `AbstractResponse.parseResponse(...)`. A `CorrelationIdMismatchException` is rethrown for ordinary non-reserved request correlations; only the SASL-reserved special case converts a particular mismatch into `SchemaException`.

This creates an important lifecycle boundary: a mismatching response reaches parsing only after the corresponding in-flight request has already been removed by `completeNext(source)`. Therefore source inspection supports an exception path after in-flight completion/removal, not a path where the request remains pending after the mismatch.

## Test evidence

NetworkClientTest contains raw `MockSelector.completeReceive(new NetworkReceive(...))` injection and matching-correlation execution. Repository search did not find a dedicated test invoking `NetworkClient.parseResponse` with a mismatching correlation or asserting `CorrelationIdMismatchException` through `NetworkClient.poll()`.

Therefore:
- lower-level raw receive injection = YES
- matching response execution = YES
- mismatch construction capability = YES
- mismatch execution through NetworkClient = NO
- direct NetworkClient mismatch assertion = NO
- post-mismatch in-flight behavior is SOURCE-DERIVED, not test-executed

## Nexo evidence boundary

This is stronger than the prior recipe-only claim because the source establishes ordering: `completeNext(source)` precedes response parsing. But it must not be promoted to executed behavior without a real test run.

No production source changed. No Kafka tests were executed by this audit. Nexo implementation remains NOT_STARTED; V21 remains forbidden/not started.
