# Nexo AB104.559 — Joint witness crash recovery

Date: 2026-09-27
Status: RESEARCH COMPLETE — DESIGN INPUT ONLY

## Evidence
Raft specifies that a leader crash during joint consensus can result in leadership under the old or joint configuration depending on what the candidate has received, while the new configuration cannot make unilateral decisions. Once the joint configuration is committed, neither old nor new can decide without the other. citeturn0search0turn0search23 The etcd-io/raft implementation persists configuration state and has an explicit restore path that reconstructs the active configuration from the snapshot's ConfState; it rejects an invalid snapshot membership state rather than inventing a configuration. citeturn0search12

## Finding
A partially committed witness transition must be recovered from the last durably justified transition state, not from whichever witness set is locally reachable.

Candidate state machine:
OLD_ACTIVE
-> JOINT_PREPARED
-> JOINT_COMMITTED
-> NEW_PREPARED
-> NEW_ACTIVE
-> OLD_DEPRECATED

Only JOINT_COMMITTED may authorize decisions requiring both sets. NEW_ACTIVE requires an independently justified commitment of the final configuration. PREPARED is never sufficient authority.

## Crash rules
1. Crash before JOINT_COMMITTED: recover OLD_ACTIVE, unless a durable independent record proves JOINT_COMMITTED.
2. Crash after JOINT_COMMITTED but before NEW_ACTIVE: recover JOINT state; neither old-only nor new-only can authorize protected anchor transitions.
3. Crash after NEW_ACTIVE: recover NEW_ACTIVE; old set cannot revive itself without a new protected transition.
4. Snapshot contains an impossible/invalid witness configuration: reject/quarantine recovery rather than synthesize a configuration.
5. Local witness availability conflicts with durable transition state: durable state wins only when its continuity/integrity basis is trusted; otherwise UNKNOWN/QUARANTINED.

## Anti-rollback invariant
There must be no accepted recovery path satisfying:
old_state < recovered_state < new_state
while allowing old authority to become active again.
The recovery decision must be anchored to a durable continuity record and, where required, independently witnessed.

## Important distinction
A prepared joint state is evidence of intent, not authority. A committed joint state is an authority boundary. A final new state is a later authority boundary. The state machine must never infer commitment from partial signatures or local reachability.

## Nexo consequence
Witness transition records need durable phase, epoch, predecessor digest, successor digest, witness-set membership, and evidence of commitment. Recovery must reconstruct the phase first, then establish a fresh recovery epoch before releasing protected authority.

Critical distinctions:
JOINT_PREPARED != JOINT_COMMITTED
JOINT_COMMITTED != NEW_ACTIVE
LOCAL_REACHABILITY != COMMITMENT
PARTIAL_SIGNATURES != AUTHORITY
RESTORED_CONFIGURATION != CURRENT_AUTHORITY
RECOVERY_SUCCESS != RECONCILIATION
