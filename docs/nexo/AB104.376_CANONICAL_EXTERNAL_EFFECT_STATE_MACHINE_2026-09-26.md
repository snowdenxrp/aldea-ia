## Required transition semantics

REQUESTED → ADMITTED
Guard: current authority, required scope/policy, target VersionSet, effect class, resource incarnation, and all admission preconditions are valid at the protected decision frontier.
Failure: REJECTED or HOLD/REVALIDATE.

ADMITTED → INTENT_DURABLE
Guard: durable intent and exact EffectID/OperationID persisted.
Failure: remain non-executable; do not externally attempt.

INTENT_DURABLE → READY
Guard: recovery/ownership fence, authority freshness, and external prerequisites are current.
Failure: HOLD/REVALIDATE or QUARANTINED.

READY → EXTERNAL_ATTEMPTED
Guard: final external gate passes; provider fence/conditional request is attached when required.
Important: this records an attempt, not confirmation.

EXTERNAL_ATTEMPTED → PROVIDER_ACKNOWLEDGED
Guard: provider response is bound to exact EffectID/OperationID and has defined semantics.
A timeout/lost response does NOT satisfy this transition.

PROVIDER_ACKNOWLEDGED → EXTERNAL_CONFIRMED
Guard: acknowledgement is sufficient under the effect-class contract OR independent reconciliation confirms exact external state.
Otherwise: RECONCILIATION_REQUIRED or UNKNOWN.

EXTERNAL_ATTEMPTED → UNKNOWN
Trigger: execution may have occurred but outcome cannot be established.

UNKNOWN → RECONCILIATION_REQUIRED
Trigger: evidence insufficient for safe classification.
UNKNOWN must not directly become SUCCESS.

RECONCILIATION_REQUIRED → EXTERNAL_CONFIRMED
Guard: evidence establishes exact effect identity/state with required trust and freshness.

RECONCILIATION_REQUIRED → REJECTED
Guard: evidence establishes non-execution/rejection.

UNKNOWN → RETRY
Only through a new admission decision. Reuse of EffectID is permitted only if provider semantics make it the same logical effect. New EffectID is a NEW EFFECT.

Any confirmed/partial effect → COMPENSATION_REQUIRED
Only if the declared effect class permits compensation. Compensation is a new protected operation.

Multi-provider:
Any participant UNKNOWN while another is confirmed → PARTIAL_COMMIT + UNKNOWN participant.
No global success state until the coordination/reconciliation contract proves the required property.

## Recovery ownership
Every recovery/reconciliation transition must carry a current RecoveryFence/owner. Recovery cannot grant itself ordinary authority.

## Forbidden shortcuts
- READY → CONFIRMED
- TIMEOUT → REJECTED
- MISSING_ACK → REJECTED
- RETRY → NEW_EFFECT by default
- LOCAL_COMMIT → EXTERNAL_CONFIRMED
- COMPENSATION → ERASE_ORIGINAL_EVENT
- PROVIDER_FAILOVER → GUARANTEE_PRESERVED without evidence
