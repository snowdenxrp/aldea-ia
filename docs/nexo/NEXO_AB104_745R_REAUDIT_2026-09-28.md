# NEXO AB104.745R — Re-audit OFLE client-test coverage

Date: 2026-09-28
Source: Apache Kafka abf522e1ca5d7f4375baddc4da004da9fcb6e9ca

Direct inspection of clients/src/test/java/org/apache/kafka/clients/consumer/internals/OffsetForLeaderEpochClientTest.java confirms exactly five tests:

1. testEmptyResponse
   - sends an empty request map;
   - receives an empty OFLE response;
   - asserts no retry and no end offsets.

2. testUnexpectedEmptyResponse
   - requests tp0;
   - receives an empty OFLE response;
   - asserts tp0 remains in partitionsToRetry and no end offset exists.
   - This is the concrete "missing requested partition / unexpected empty response" coverage.

3. testOkResponse
   - requests tp0;
   - returns Errors.NONE, leaderEpoch=1, endOffset=10;
   - asserts no retry and exact endOffset fields.

4. testUnauthorizedTopic
   - returns TOPIC_AUTHORIZATION_FAILED;
   - asserts future failure with TopicAuthorizationException and unauthorized topic.

5. testRetriableError
   - returns LEADER_NOT_AVAILABLE;
   - asserts future does not fail, tp0 remains retryable, and no end offset exists.

The helper prepareOffsetForLeaderEpochResponse(...) directly constructs the OFLE response data used by these tests.

## Explicit gaps confirmed by the file

There is no test in this class for:
- an unrequested response partition;
- duplicate response partition;
- duplicate with conflicting error/order;
- deliberate OFLE response correlation mismatch;
- arbitrary mixed-error response;
- exhaustive reducer error classes.

The five tests therefore establish a useful client-layer baseline but are not an exhaustive reducer/adversarial matrix.

## Important distinction

testUnexpectedEmptyResponse does provide direct execution evidence for a requested partition absent from the response. It is more precise than saying "missing requested partition coverage is not established."

However, it is an empty response, not a response containing other/unrequested partitions. Therefore:
MISSING_REQUESTED_IN_EMPTY_RESPONSE = EXECUTED
UNREQUESTED_RESPONSE_PARTITION = NOT_EXECUTED

Correlation mismatch remains NOT EXECUTED in this class.
