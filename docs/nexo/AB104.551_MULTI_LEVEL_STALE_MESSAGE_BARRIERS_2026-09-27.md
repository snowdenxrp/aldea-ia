# Nexo AB104.551 — Multi-level stale-message barriers

Date: 2026-09-27
Status: RESEARCH COMPLETE — DESIGN INPUT ONLY

## Finding
No single barrier is universally interchangeable with a retained tombstone. A target incarnation or authority epoch can make an old message structurally stale only if the receiving boundary durably enforces that generation. A provider high-water mark can reject older fences only if it survives provider recovery. An archival witness can prove historical facts, but it does not itself enforce future rejection. These are complementary controls, not substitutes by default.

## Evidence
Kafka explicitly bounds tombstone visibility with delete.retention.ms and states that lagging consumers can miss tombstones after that interval. etcd similarly makes revisions before compaction inaccessible and uses retention windows so slow watchers can catch up. ZooKeeper session expiration deletes ephemeral state at the coordination service, showing the same principle: authority about ownership/expiry resides in the authoritative service, not merely in a client's local observation. citeturn0search0turn0search1turn0search12turn0search11

## Barrier capability matrix
1. Tombstone: historical rejection marker while retained; weak after GC unless another barrier replaces it.
2. TargetIncarnation: strong stale-target rejection if provider atomically checks incarnation; does not prove the old attempt never happened.
3. AuthorityEpoch/FenceRevision: strong stale-authority rejection if the provider durably enforces high-water marks; not historical nonoccurrence proof.
4. Provider high-water mark: enforces monotonic provider-side fence ordering; requires durable crash/restore semantics.
5. Archival witness: supports historical reconstruction and reconciliation; does not by itself block a late writer.
6. Retention/coverage bound: establishes when historical artifacts may be safely compacted, but only if the bound is itself justified and monitored.

## Candidate composite barrier
For protected effects, prefer a layered tuple:
TargetIdentity + TargetIncarnation + AuthorityEpoch + FenceRevision + EffectID
with provider-side conditional admission and a durable high-water mark. Preserve archival evidence for the interval where negative claims or dispute resolution may still be required.

## Key distinction
A new incarnation can replace a tombstone as an enforcement mechanism only when every relevant producer/provider rejects the old incarnation. An archive cannot substitute for that enforcement. Conversely, a fence can prevent future stale admission but cannot prove that an old request was never accepted before the fence advanced.

## Adversarial timeline
T0: Effect E authorized under incarnation I1, fence F1.
T1: E becomes UNKNOWN.
T2: target moves to I2 / fence F2.
T3: tombstone for E is compacted.
T4: delayed E(F1,I1) arrives.
Safe provider: rejects because I1/F1 is stale.
Unsafe provider: accepts because it only checks current existence, producing a new hazard.
Archive witness: may establish that E existed historically, but cannot prevent T4.

## Critical distinctions
- INCARNATION_FENCE != HISTORICAL_NONOCCURRENCE
- FENCE_HIGH_WATER_MARK != ARCHIVAL_PROOF
- ARCHIVAL_PROOF != FUTURE_ENFORCEMENT
- TOMBSTONE_GC != SAFE_REPLAY
- NEW_EPOCH != RETROACTIVE_CANCEL
- RETENTION_WINDOW != WORLD_TRUTH
- LOCAL_GENERATION != PROVIDER_ENFORCED_GENERATION
- RECONCILIATION_EVIDENCE != ADMISSION_CONTROL

## Nexo implication
Nexo should treat enforcement barriers and evidence barriers as separate classes. A safe cleanup transition requires both: (a) an enforcement barrier that makes obsolete operations inadmissible, and (b) sufficient historical evidence coverage for any remaining negative-effect or dispute claims. Garbage collection must not silently destroy the only mechanism supporting either property.
