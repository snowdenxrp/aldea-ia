## Finding

The earlier empty workflow-run query was not a valid runtime verdict. The connector's fetch_commit_workflow_runs action is documented by its own tool contract as filtering to pull-request-triggered runs, so it cannot be used to conclude that a push-triggered run for commit dcef7aab2f8c6c2cb41a2780bd79a3a4b092475b did not exist.

GitHub's current documentation states:
- push workflows can be filtered by branch/path;
- workflow_dispatch requires the workflow file on the default branch;
- workflow events generated using GITHUB_TOKEN do not create new workflow runs, except workflow_dispatch/repository_dispatch;
- pull_request workflows can provide an observable CI trigger path.
