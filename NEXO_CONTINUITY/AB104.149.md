## INVESTIGAR
Rechecked Node.js v22 filesystem semantics. Promise-based fs operations use the threadpool and are not synchronized/threadsafe; concurrent modifications require explicit coordination. `writeFile` supports `flush:true`, which flushes the file descriptor after successful writing, but that does not make a filesystem checkpoint atomic with an external side effect. citeturn0search2turn0search1
